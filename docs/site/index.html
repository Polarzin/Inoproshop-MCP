InoProShop 的
MCP 工程接口

通过公开 ScriptEngine 接口，在 MCP 客户端中创建和编辑工程，读写 ST 程序，执行原生编译、保存和启动包导出。

一个面向 PLC 工程操作的小工具，附三轴飞剪示例。

查看使用说明了解飞剪示例

支持的工程操作

通过 InoProShop 原生工程接口执行。

01

创建与编辑

创建空工程容器，查看工程结构，读取和修改 ST 程序及工程对象。

create_empty · read · write
02

编译与保存

调用原生编译器获取诊断信息，保存工程，并重新打开检查修改结果。

compile · save · tree
03

导出启动包

导出软件控制器的原生启动包，用于后续按官方流程部署与运行。

export_boot

硬件实践

前期工程工具已在自有硬件平台上验证过工程读写、编译与下载操作。当前公开版的三轴飞剪示例在软件 PLC 上验证。

使用说明

先准备本机环境，再连接 MCP 客户端。

  1. 01

    准备环境

    Windows、Node.js ≥ 18，以及带 ScriptEngine 的兼容 InoProShop。构建飞剪示例需匹配的软件控制器设备描述与运动组件。

  2. 02

    配置客户端

    安装依赖，将 server.mjs 配置到支持 stdio MCP 的客户端，并填写本机 IDE 路径。

  3. 03

    执行工程操作

    创建空工程或读写已有 ST；运行飞剪示例时，先准备空白控制器模板。

MCP 客户端配置示例
{
  "mcpServers": {
    "inoproshop": {
      "command": "node",
      "args": ["C:/path/to/inoproshop-mcp/server.mjs"],
      "env": {
        "INOPROSHOP_EXE": "C:/path/to/InoProShop.exe",
        "INOPROSHOP_PROFILE": "InoProShop(V1.9.1.6)"
      }
    }
  }
}

将示例路径替换为本机绝对路径。
